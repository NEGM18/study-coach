  • ☐ dev exists; API and worker auto-deploy to staging; smoke test green

  • ☐ Each model: v1 in DVC with a model card and an honest test-set comparison against its stub (A also against the re-measured PFA)
  • ☐ No professor names or student data in Git; real kappa ≥ 0.80 for model C
  • ☐ A model goes live on staging only if it passes every box in README 5.4 — otherwise it stays stub
  • ☐ Release week-2 merged to main, tagged v0.2.0

7. Rules that matter most this week

  • New libraries (fastapi, sentence-transformers, …): ask Omar first; add to pyproject.toml in the same PR.
  • Model versions only from *_MODEL_VERSION env vars; paths from YAML; never hard-coded.
  • Models saved as <model>_model_v<n>/ in DVC with model_card.md.
  • Migrations are new numbered files; schema changes update schemas.py in the same PR.
  • The app talks only to /api/v1 through api_client.dart; no secrets in the app; Arabic-first RTL.
  • Seed 42; splits by student / speaker / lecture; never paste raw student data, audio or keys into a chat.
